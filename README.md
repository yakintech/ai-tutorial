# Yapay Zeka ve Matematik

Medium'daki *Yapay Zeka ve Matematik* yazı dizisinin kod örnekleri. Her klasör bir yazıya karşılık gelir; yazıdaki sayılar ile koddaki sayılar birebir aynıdır, kopyala-çalıştır-doğrula.

## Kurulum

```bash
pip install -r requirements.txt
```

Tek bağımlılık `numpy`.

## Bölümler

| # | Klasör | Yazı | Konu |
|---|--------|------|------|
| 1 | [`01_vectors_cosine`](01_vectors_cosine/) | [Kosinüs'le Benzerlik Ölçümü](https://cagatayyildiz87.medium.com/yapay-zeka-ve-matematik-kosin%C3%BCsle-benzerlik-%C3%B6l%C3%A7%C3%BCm%C3%BC-5cf90d0a2654) | Nokta çarpımı, vektör büyüklüğü, iki şeyin ne kadar benzediğini ölçmek |
| 2 | [`02_matrix_neuron`](02_matrix_neuron/) | Nöron, Yani Karar Verme Sanatı *(yakında)* | Ağırlıklı toplam, bias, ReLU, tek karardan yüzlerce karara (matris) |
| 3 | `03_...` | *(sırada)* | Ağırlıkları kim belirliyor? Hata ölçmek ve öğrenmek |

## Çalıştırma

```bash
python 01_vectors_cosine/main.py
python 02_matrix_neuron/home_sample.py
python 02_matrix_neuron/batch_example.py
```
